- DM Mono v16, weight 400: https://fonts.gstatic.com/s/dmmono/v16/aFTU7PB1QTsUX8KYthqQBA.woff2
- DM Mono v16, weight 500: https://fonts.gstatic.com/s/dmmono/v16/aFTR7PB1QTsUX8KYvumzEYOtbQ.woff2

These are the existing design's typefaces, hosted here so the same-origin
production content security policy permits them without third-party requests.
Versioned filenames permit long-lived caching; rename assets when updating them.
Public font CORS headers also allow session replay to load the same files.
The Latin subsets cover the current English website, including curly quotes.
Add the appropriate subsets if the website is localized in the future.
